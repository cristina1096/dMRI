# Joint Fit Across Conditions: Can the Conventional Model Mimic the Layer? (Walls) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For a single free-decay curve, a conventional model with a fitted θ reproduces the layer within noise unless ρw/D ≳ 3 (Review C1 follow-up). This plan finds out whether fitting **several conditions jointly with one shared relaxivity** separates the two:
- **conditions:** compartment sizes w, diffusivities D, and a multi-echo train in TE;
- **shared parameters:** surface physics shared across conditions (ρ, h, profile), with the conventional model allowed one shared ρ_c.
- **output:** the **minimum SNR** at which the conventional model is rejected, over a grid of profile, h and ρw/D.

A secondary question: can the profiles be told apart from each other, by fitting a step layer to linear or exponential data?

**Architecture:**
- **Data.** Everything runs on the exact 1D continuum benchmark (`research/phase2/continuum.jl`: unit-tested, validated against Monte Carlo, checked against exact eigenvalues). It is noise-free and has no timestep bias.
- **Noise-free test.** For "data" y = S_layer(t; conditions), the minimum of χ² = Σ (y − S_conv(t; ρ_c, R₂ᵇ))² / σ² over the conventional parameters is the **non-centrality λ** of the goodness-of-fit test of the conventional model. With σ = 1/SNR (Gaussian noise, in units of S(0)), λ = SNR²·L, where L = min Σ residual².
- **Detection criterion.** The conventional model is rejected at α = 0.05 with power 0.8 when λ ≥ λ\*(df), df = number of readouts − number of fitted parameters. The required SNR is √(λ\*/L).
- **Tools.** The non-central χ² is computed from SpecialFunctions' incomplete gamma, and the fits use a scan plus golden section. Both are unit-tested; no new dependencies.
- **Spot check.** One Monte Carlo spot check at strong ρ validates the continuum for several w there.

**Tech Stack:** Julia 1.12, `research/phase2/` (continuum.jl, harness.jl, sensitivity.jl), SpecialFunctions (already in `research/baseline`), CairoMakie, `Test` stdlib.

**Spec:**

## Global Constraints

- Work only on branch `cc/near-surface-r2`.
- **Conditions (shared physics):** one ρ, h and profile for all conditions; the exponential cutoff equals each condition's w. Intrinsic T₂ = 2 s (R₂ᵇ = 1/2000), as in P2.5.6. Condition sets:
  - **S1:** single condition, w = 2, D = 3 (control: reproduces the single-curve result with a calibrated test).
  - **S2 (w-set):** w ∈ {1, 2, 5}, D = 3.
  - **S3 (D-set):** D ∈ {1, 2, 3}, w = 2. Changing D in practice (temperature, for example) may also change ρ; that is noted as a limitation, not modelled.
  - **S4 (w × D):** w ∈ {1, 2, 5} × D ∈ {1, 2, 3}.
- **Readouts:** multi-echo TE = 5, 10, … up to the last TE where the conventional reference signal (ρ_c = ρ, R₂ᵇ = 1/2000) is ≥ 0.05, capped at 200 ms. This keeps magnitude data in the Gaussian regime (S·SNR ≥ 5 at SNR ≥ 100). A **two-point variant** (TE = 0 and the single TE where S_conv ≈ e^(−1), rounded to 5 ms) is reported for comparison with the P2.5.6 criterion.
- **Conventional model fitted:** one shared ρ_c (= θ√(D/π) per condition), with R₂ᵇ either known (variant **K**) or free and shared (variant **F**).
- **Control (variant P):** a separate ρ_c per condition. This is the "no sharing" reference: it shows how much of the separation comes from sharing ρ.
- **Grid:**
  - profiles step, linear, exponential;
  - h ∈ {0.02, 0.1, 0.2, 0.5} µm (a physical thickness, the same in every condition);
  - ρ such that ρ·2/3 (ρw/D at w = 2, D = 3) ∈ {0.01, 0.03, 0.1, 0.3, 1, 3};
  - step is excluded when h > w/2 for any w in the set (h = 0.5 with w = 1 is allowed, at h = w/2).
- **Detection:** α = 0.05, power 0.8. Required SNR = √(λ\*(df)/L). Results are reported against SNR 100 and 200 and are never pass/fail.
- **Solver resolution:** N = 1500 cells for fits (within 4 % of N = 6000 at the map extremes, C1 follow-up). The Task 4 spot check uses N = 3000. Threaded scripts set `BLAS.set_num_threads(1)` so the Julia threads don't oversubscribe the CPU.

## Review Focus

1. **The fit must find the global minimum.** A local or edge minimum would understate L and overstate the required SNR. Test: Task 1 (self-fit recovers the true ρ_c and R₂ᵇ with L ≈ 0; the scan range is wide; edge minima flagged, as in C1, where the conventional model saturates at D·π²/w²).
2. **The non-central χ² must be right**, since the required SNR depends on λ\*. Test: Task 1 (central case equals the χ² cdf; mean df + λ by numerical integration; known λ\* for df = 1).
3. **Readouts per condition must be fixed by the conventional reference, not by the data being fitted.** Otherwise the test is circular. Test: Task 1 (`readouts` depends only on (w, D, ρ, R₂ᵇ)).
4. **Sharing must really be shared.** In variants K and F, ρ_c is one number across all conditions; in P it is per condition. Test: Task 1 (P never gives a larger L than F on the same data).
5. **R₂ᵇ free can absorb part of the difference**, and that is a real feature of the test, not a bug. The record must show K and F side by side. Test: Task 2 output columns.

```julia
"""
    continuum_basis(; w, D, layer=nothing, surface=0.0, N=3000)

Eigen-decomposition once: decay rates λ_k and weights ⟨u0, φ_k⟩² for a uniform start, so that the signal at any times
and any bulk R2 is Σ_k weight_k e^(−λ_k t) e^(−R2 t) without a new decomposition.
"""
function continuum_basis(; w, D, layer=nothing, surface=0.0, N=3000)
    F = eigen(continuum_operator(; w=w, D=D, layer=layer, surface=surface, N=N))
    return (rates=F.values, weights=(F.vectors' * fill(1 / sqrt(N), N)) .^ 2)
end

"Signal from a `continuum_basis` at `times` with bulk rate `R2_bulk`."
basis_signal(b, times; R2_bulk=0.0) = [sum(b.weights .* exp.(-b.rates .* t)) * exp(-R2_bulk * t) for t in times]
```

`research/phase2/jointfit.jl`:

```julia
# Joint fit across conditions (P2.5.8): can the conventional model, with one shared relaxivity ρ_c (and optionally a
# shared unknown bulk R2), reproduce the layer model across several w, D and a multi-echo train? Noise-free data from
# the continuum benchmark; the minimum residual sum of squares L gives the non-centrality λ = SNR²·L of the χ² test.

using SpecialFunctions

struct Condition
    w::Float64
    D::Float64
end

"""
    readouts(c, ρ; R2_bulk, smin=0.05, tmax=200.0, dt=5.0)

TE = dt, 2dt, … up to the last TE where the CONVENTIONAL reference (surface ρ, bulk R2_bulk) is ≥ smin, capped at tmax.
Depends only on (w, D, ρ, R2_bulk), never on the data being fitted.
"""
function readouts(c::Condition, ρ; R2_bulk, smin=0.05, tmax=200.0, dt=5.0)
    t = collect(dt:dt:tmax)
    S = basis_signal(continuum_basis(w=c.w, D=c.D, surface=ρ, N=1500), t; R2_bulk=R2_bulk)
    k = findlast(>=(smin), S)
    return isnothing(k) ? t[1:1] : t[1:k]
end

"Layer data per condition: (times, S) with the readouts of the conventional reference at the same ρ."
function layer_data(conds, shape, ρ, h; R2_bulk, N=1500)
    [(t = readouts(c, ρ; R2_bulk=R2_bulk); (t, basis_signal(continuum_basis(w=c.w, D=c.D, layer=(shape, ρ, h), N=N), t; R2_bulk=R2_bulk))) for c in conds]
end

"Golden-section minimum of f on [a, b]."
function golden(f, a, b; iters=40)
    g = (sqrt(5) - 1) / 2
    x1, x2 = b - g * (b - a), a + g * (b - a)
    f1, f2 = f(x1), f(x2)
    for _ in 1:iters
        if f1 < f2
            b, x2, f2 = x2, x1, f1; x1 = b - g * (b - a); f1 = f(x1)
        else
            a, x1, f1 = x1, x2, f2; x2 = a + g * (b - a); f2 = f(x2)
        end
    end
    return f1 < f2 ? (x1, f1) : (x2, f2)
end

"Scan of f over grid, then golden section between the neighbours of the best point; flags an edge minimum."
function scan_golden(f, grid; iters=40)
    v = f.(grid)
    k = argmin(v)
    at_edge = k == 1 || k == length(grid)
    x, fx = golden(f, grid[max(k - 1, 1)], grid[min(k + 1, length(grid))]; iters=iters)
    return fx <= v[k] ? (x, fx, at_edge) : (grid[k], v[k], at_edge)
end

"Best shared bulk R2 (known = fixed) for given model signals without bulk: minimise Σ (y − S0·e^(−R t))²."
function best_bulk(data, S0s; known, free)
    sse(R) = sum(sum(abs2, y .- s .* exp.(-R .* t)) for ((t, y), s) in zip(data, S0s))
    free || return (known, sse(known))
    R, v = golden(sse, 0.0, 0.05; iters=60)
    return (R, v)
end

"""
    fit_conventional(data, conds; mode, R2_bulk_known, N=1500)

mode :K — one shared ρ_c, bulk R2 known; :F — one shared ρ_c and one shared free bulk R2; :P — a separate ρ_c per
condition (bulk known). Returns (L = min Σ residual², rho_c, R2b, at_edge, df).
"""
function fit_conventional(data, conds; mode, R2_bulk_known, N=1500)
    ρ_guess = 0.0
    n = sum(length(d[1]) for d in data)
    if mode == :P
        L = 0.0; ρs = Float64[]; edge = false
        for (d, c) in zip(data, conds)
            f(lr) = sum(abs2, d[2] .- basis_signal(continuum_basis(w=c.w, D=c.D, surface=exp(lr), N=N), d[1]; R2_bulk=R2_bulk_known))
            x, fx, e = scan_golden(f, log(1e-5):0.25:log(1e3))
            L += fx; push!(ρs, exp(x)); edge |= e
        end
        return (L=L, rho_c=ρs, R2b=R2_bulk_known, at_edge=edge, df=n - length(conds))
    end
    free = mode == :F
    function g(lr)
        S0s = [basis_signal(continuum_basis(w=c.w, D=c.D, surface=exp(lr), N=N), d[1]) for (d, c) in zip(data, conds)]
        best_bulk(data, S0s; known=R2_bulk_known, free=free)[2]
    end
    x, fx, e = scan_golden(g, log(1e-5):0.25:log(1e3))
    S0s = [basis_signal(continuum_basis(w=c.w, D=c.D, surface=exp(x), N=N), d[1]) for (d, c) in zip(data, conds)]
    R2b, _ = best_bulk(data, S0s; known=R2_bulk_known, free=free)
    return (L=fx, rho_c=exp(x), R2b=R2b, at_edge=e, df=n - (free ? 2 : 1))
end

"""
    fit_step_layer(data, conds; R2_bulk, N=1500)

Step layer with free shared (ρ, h) fitted to the data (bulk known): profile identifiability. Coarse 2D scan in
(log ρ, log h) then coordinate-wise golden refinement. h is limited to ≤ min(w)/2 (step rule). Returns (L, rho, h, df).
"""
function fit_step_layer(data, conds; R2_bulk, N=1500)
    hmax = minimum(c.w for c in conds) / 2
    f(lr, lh) = sum(sum(abs2, d[2] .- basis_signal(continuum_basis(w=c.w, D=c.D, layer=("step", exp(lr), exp(lh)), N=N), d[1]; R2_bulk=R2_bulk))
                    for (d, c) in zip(data, conds))
    lrs = log(1e-4):0.5:log(1e2); lhs = log(0.005):0.25:log(hmax)
    best = (Inf, 0.0, 0.0)
    for lr in lrs, lh in lhs
        v = f(lr, lh)
        v < best[1] && (best = (v, lr, lh))
    end
    _, lr, lh = best
    for _ in 1:6
        lr, _ = golden(x -> f(x, lh), lr - 0.5, lr + 0.5; iters=30)
        lh, v = golden(x -> f(lr, x), max(lh - 0.25, log(0.005)), min(lh + 0.25, log(hmax)); iters=30)
        best = (v, lr, lh)
    end
    n = sum(length(d[1]) for d in data)
    return (L=best[1], rho=exp(best[2]), h=exp(best[3]), df=n - 2)
end

"Central χ² cdf with df degrees of freedom (regularised lower incomplete gamma)."
chisq_cdf(x, df) = x <= 0 ? 0.0 : gamma_inc(df / 2, x / 2)[1]

"Non-central χ² cdf as a Poisson mixture of central χ² cdfs."
function ncchisq_cdf(x, df, λ)
    λ == 0 && return chisq_cdf(x, df)
    μ = λ / 2
    s = 0.0
    jmax = ceil(Int, μ + 12 * sqrt(μ) + 50)
    lw = -μ
    for j in 0:jmax
        j > 0 && (lw += log(μ) - log(j))
        s += exp(lw) * chisq_cdf(x, df + 2j)
    end
    return s
end

"Quantile of the central χ² by bisection."
function chisq_quantile(p, df)
    lo, hi = 0.0, max(10.0, 10df)
    while chisq_cdf(hi, df) < p
        hi *= 2
    end
    for _ in 1:200
        mid = (lo + hi) / 2
        chisq_cdf(mid, df) < p ? (lo = mid) : (hi = mid)
    end
    return (lo + hi) / 2
end

"Non-centrality λ* at which the χ² test (level α) rejects with probability `power`."
function lambda_star(df; α=0.05, power=0.8)
    c = chisq_quantile(1 - α, df)
    lo, hi = 0.0, 10.0
    while 1 - ncchisq_cdf(c, df, hi) < power
        hi *= 2
    end
    for _ in 1:200
        mid = (lo + hi) / 2
        1 - ncchisq_cdf(c, df, mid) < power ? (lo = mid) : (hi = mid)
    end
    return (lo + hi) / 2
end

"SNR (σ = 1/SNR per readout) at which λ = SNR²·L reaches λ*(df)."
required_snr(L, df; α=0.05, power=0.8) = L > 0 ? sqrt(lambda_star(df; α=α, power=power) / L) : Inf
```

```julia
    "S2" => [Condition(w, 3.0) for w in (1.0, 2.0, 5.0)],
    "S3" => [Condition(2.0, D) for D in (1.0, 2.0, 3.0)],
    "S4" => [Condition(w, D) for w in (1.0, 2.0, 5.0) for D in (1.0, 2.0, 3.0)])
const RWD = [0.01, 0.03, 0.1, 0.3, 1.0, 3.0]          # ρw/D at the reference w = 2, D = 3
const HS = [0.02, 0.1, 0.2, 0.5]

"Two-point readout per condition: TE where the conventional reference is closest to e^(−1), rounded to 5 ms (TE = 0 implicit, S(0) = 1)."
two_point(data, conds, ρ) = [(t = readouts(c, ρ; R2_bulk=R2B, smin=exp(-1)); ([t[end]], d[2][findfirst(==(t[end]), d[1])] .+ 0.0)) for (d, c) in zip(data, conds)]

rows = NamedTuple[]
Threads.@threads for job in [(shape, h, rwd, set) for shape in ("step", "linear", "exponential") for h in HS for rwd in RWD for set in sort(collect(keys(SETS)))]
    shape, h, rwd, set = job
    conds = SETS[set]
    (shape == "step" && any(h > c.w / 2 for c in conds)) && continue
    ρ = rwd * 3.0 / 2.0
    data = layer_data(conds, shape, ρ, h; R2_bulk=R2B)
    for (kind, dat) in (("multi-echo", data), ("two-point", two_point(data, conds, ρ)))
        for mode in (:K, :F, :P)
            (kind == "two-point" && mode != :K) && continue          # one readout per condition: only a shared ρ_c (K) leaves df ≥ 1 (sets with ≥ 2 conditions)
            f = fit_conventional(dat, conds; mode=mode, R2_bulk_known=R2B)
            snr = f.df >= 1 ? required_snr(f.L, f.df) : NaN
            row = (shape=shape, h_um=h, rho_w_over_D=rwd, rho=ρ, set=set, readout=kind, variant=String(mode),
                n=sum(length(d[1]) for d in dat), df=f.df, L=f.L, required_snr=snr,
                rho_c_over_rho=mode == :P ? NaN : f.rho_c / ρ, R2b_fit=f.R2b, at_edge=f.at_edge)
            lock(LK) do
                push!(rows, row)
            end
        end
    end
end
sort!(rows, by=r -> (r.shape, r.h_um, r.rho_w_over_D, r.set, r.readout, r.variant))
for r in rows
    @printf("%-11s h=%.2f ρw/D=%-5g %s %-10s %s: n=%3d L=%.2e required SNR %s%s\n", r.shape, r.h_um, r.rho_w_over_D, r.set, r.readout, r.variant,
        r.n, r.L, isfinite(r.required_snr) ? @sprintf("%.3g", r.required_snr) : "∞", r.at_edge ? " (fit at edge)" : "")
end
write_csv(joinpath(OUT, "grid.csv"), rows)
write_json(joinpath(OUT, "summary.json"), Dict("provenance" => provenance(), "R2_bulk" => R2B, "rows" => rows,
    "note" => "required SNR: α = 0.05, power 0.8, Gaussian σ = 1/SNR per readout; noise-free continuum data; K = bulk known, F = bulk free (shared), P = ρ_c per condition"))
println("saved to $OUT")
```

```julia
# P2.5.8 spot check — the continuum benchmark at strong relaxation, where the joint fit becomes decisive and the Monte Carlo
# has not been compared before: exponential h = 0.2, ρw/D = 1 (ρ = 1.5), w = 1, 2, 5, D = 3, bulk 1/2000. Monte Carlo
# τ = min(tau_for, 0.03 w²/D)/4 (a quarter of the adopted constraint, after C1), readouts every 0.5 ms to 5 ms
# (S ≳ 0.05), seeds 1–10, 50000 spins. Compare S_layer and S_conv (θ = ρ√(π/D)) with continuum_signal per readout.
# Pass: |z| ≤ 3 everywhere (z = (MC − continuum)/SEM).
#
# Run: julia --project=research/baseline -t 8 research/phase2/p2_5_jointfit_mc_check.jl

include(joinpath(@__DIR__, "sensitivity.jl"))

                                ("conventional", baseline_walls(theta=theta_for(ρ; D=D), w=w), continuum_signal(w=w, D=D, times=T, surface=ρ, R2_bulk=R2B, N=3000)))
        r = run_walls(geom; D=D, R2_bulk=R2B, timestep=τ, times=T, nspins=50_000)
        z = (r.mean .- cont) ./ max.(r.sem, 1e-12)
        push!(rows, (w=w, model=label, tau_ms=τ, max_abs_z=maximum(abs.(z[2:end])), max_abs_diff=maximum(abs.(r.mean .- cont)), S_end_mc=r.mean[end], S_end_cont=cont[end]))

    end
end
```
